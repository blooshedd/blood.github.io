Пишем сайт (электронный учебник) на HTML и CSS

Цель урока:
 Создание «самописного» сайта средствами HTML и CSS .
К оглавлению

Задание по созданию электронного учебника

    1. Электронный учебник должен быть выполнен во фрэймовой структуре, со следующими обязательными пунктами в меню:

  1. Главная

  2. Глава 1

  3. Глава 2

  4. ...

  5. Глоссарий

  6. Список литературы

    2. Создать стилевой файл (style.css) и подключить его ко всем основным страницам сайта.

    3. В стилевом файле добавить стили для следующих тегов:

  • body { }
    1. фон страницы
  • p { }
    1. семейство шрифта
    1. выравнивание текста
    1. цвет текста
    1. размер шрифта
  • a { }
    1. подчеркивание
    1. цвет
  • h1 { }
    1. оформление шрифта
    1. оформление текста
  • h2 { }
  • h3 { }
  • div { }
  • ul { }
    1. оформление списков
  • table { }
    1. оформление табличных данных

3. Все изображения оформить в тег div с заданным стилем. Добавить подписи для изображений.

4. В тексте учебника обязательно должны быть списки (маркированные или/и нумерованные).

5. Добавить аудио или видео фрагменты учебного назначения.

6. Добавить табличные данные и свойства стилей для таблицы.

7. Понятия или термины в основном тексте учебника должны быть оформлены как ссылки на объяснение данного понятия в глоссарии.
